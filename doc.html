توثيق رفع مشروع باستخدام Git من لينكس إلى GitHub

الخطوة 1: تهيئة المشروع كمستودع Git

git init

تهيئة مجلد المشروع كمستودع Git.

الخطوة 2: ربط المشروع بالمستودع على GitHub

git remote add origin https://github.com/username/repo.git

ربط المستودع المحلي بالمستودع البعيد على GitHub.

الخطوة 3: إضافة كل الملفات إلى Git

git add .

إضافة جميع الملفات لتتبعها في commit القادم.

الخطوة 4: إنشاء commit محلي

git commit -m "أول رفع للمشروع"

إنشاء نقطة حفظ للتغييرات.

الخطوة 5: تحديد اسم الفرع ورفعه

git branch -M main
git push -u origin main

تحديد اسم الفرع الرئيسي ورفعه للمستودع البعيد.

💥 مشكلة 1: Authentication Failed

ظهر الخطأ:

fatal: Authentication failed

الحل: استخدام Personal Access Token (PAT) بدلاً من كلمة المرور.

أدخل التوكن في مكان كلمة السر عند الطلب.

💥 مشكلة 2: رفض Git الدفع لأن المستودع يحتوي على ملفات

! [rejected]        main -> main (fetch first)
error: failed to push some refs to ...

الحل: إجبار Git على استبدال ما في GitHub بمشروعك المحلي بالكامل 

git push --force origin main

✅ في النهاية: تم رفع الملفات بنجاح

بعد تجاوز مشاكل المصادقة والتعارض بين الملفات المحلية والبعيدة، تم رفع آلاف الملفات الصغيرة من نظام لينكس إلى GitHub باستخدام الطرفية (Git Bash أو Terminal)، وتم تجنب قيود GitHub Desktop.
